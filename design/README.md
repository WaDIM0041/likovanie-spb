# Визуальный макет главной

14.10.2026. Открыть `index.html` локально или через HTTP-сервер из корня проекта. Это дизайн-прототип этапа 2, не опубликованный сайт.

Палитра: сценический бордовый #361C2A, красный #AE2037, светлый #FFFAF2, текст #242226, вспомогательный #68616A. Красный связан со сценическими костюмами ансамбля. Выразительная часть — фотография и крупная типографика; остальные блоки спокойные. Прототип использует системные Georgia и Segoe UI без внешних запросов. Финальные лицензированные шрифты выбираются после согласования.

Проверка замысла: концепция связана с реальными народными костюмами и сценой; вместо одинаковых карточек используются концертная композиция, список наград и крупный блок школы. Подбор группы интерактивный. У наград нет выдуманных годов и количества побед. Изображение занятия общее, не изображает специально выбранную возрастную группу.

Функциональность: навигация по секциям, переключение возрастов, раскрытие примечаний, реальные телефон/почта/карта. Добавлены Framer Motion и сценический фон; подробности в `docs/motion-design.md`. Формы и доставка заявок не подключены. Нет внешней аналитики, автоматически проигрываемого видео и сетевых шрифтов. Макет закрыт от индексации.

Для итогового сайта предстоят отдельные страницы, CMS, актуальные данные, изображения разных размеров, анимации Framer Motion, обработка заявок и SEO. Существующие package.json, scripts и vendor не изменены.

Проверено в локальном Chrome 14.10.2026: ширины 1440, 768, 390, 320 px, загрузка изображений, отсутствие переполнения страницы, выбор возраста, один активный переключатель, один H1, reduced motion, отсутствие ошибок JavaScript. Протокол — `check-results.json`. Скриншоты компьютера и телефона просмотрены. Производительность, экранный диктор и реальная доставка заявок не проверялись. Локальный HTTP-сервер недоступен браузерному инструменту; проверка выполнена через file URL.
