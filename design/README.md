# Визуальный макет главной

14.10.2026. Открыть через HTTP-сервер из корня проекта: корневой `index.html` публикуется на GitHub Pages, `design/index.html` служит дополнительным предпросмотром. Для локального продолжения в Codex см. `docs/codex-handoff.md`.

Палитра: сценический бордовый #361C2A, красный #AE2037, светлый #FFFAF2, текст #242226, вспомогательный #68616A. Красный связан со сценическими костюмами ансамбля. Выразительная часть — фотографии, крупная типографика и интерактивная 3D-сцена. Используются системные Georgia/Segoe UI и локальный лицензированный Cormorant Garamond в футере.

Проверка замысла: концепция связана с реальными народными костюмами и сценой; вместо одинаковых карточек используются концертная композиция, список наград и крупный блок школы. Подбор группы интерактивный. У наград нет выдуманных годов и количества побед. Изображение занятия общее, не изображает специально выбранную возрастную группу.

Функциональность: навигация по секциям, переключение возрастов, раскрытие примечаний, реальные телефон/почта/карта. Добавлены Framer Motion, Three.js, параллакс, автоматическая смена сцен и локальная синемаграфия с паузой; подробности в `docs/motion-design.md`. Формы подготавливают письмо, сервер доставки заявок не подключён. Нет внешней аналитики и сетевых шрифтов. Предпросмотр закрыт от индексации.

Для итогового сайта предстоят отдельные страницы, CMS, уточнение актуальных данных, изображения разных размеров, сервер обработки заявок и запуск индексации на рабочем домене. Исходники Motion восстанавливаются через `scripts/restore-motion.ps1`; готовые локальные JS-сборки включены в репозиторий.

Проверено в локальном Chrome 14.10.2026: ширины 1440, 768, 390, 320 px, загрузка изображений, отсутствие переполнения страницы, выбор возраста, один активный переключатель, один H1, reduced motion, отсутствие ошибок JavaScript. Протокол — `check-results.json`. Скриншоты компьютера и телефона просмотрены. Производительность, экранный диктор и реальная доставка заявок не проверялись. Локальный HTTP-сервер недоступен браузерному инструменту; проверка выполнена через file URL.
