# Motion и фон «Ликования»

Реализовано в локальном макете `design/index.html`. Движение основано на сцене: спокойный выход, свет и смена фокуса.

- Первый экран: последовательное раскрытие текста, 650 мс, шаг 90 мс; фото раскрывается за 1 с.
- Достижения: однократное появление списка в зоне видимости, 450 мс, шаг 90 мс. Текст не скрыт до прокрутки.
- Возрастные программы: короткий выход 120 мс и вход 300 мс. Быстрое переключение отменяет предыдущий переход.
- Кнопки: небольшое сжатие при нажатии и возврат пружиной.
- Фон: бордовый сценический свет с золотистыми лучами. На компьютере слегка реагирует на прокрутку; на телефоне статичен. Бесконечных анимаций нет.
- Reduced motion: отключены визуальные трансформации и прозрачность, доступность текста дополнительно защищена CSS. Контент остаётся доступным без JS; первоначальный выбор возраста имеет HTML-представление.

Использован реальный локальный пакет Framer Motion 14.2.0 через `framer-motion/dom`: animate, stagger, inView, scroll. Это DOM API библиотеки для существующего HTML-макета, без переноса всей страницы в React. Исходник `design/motion-source.js`, сборка `scripts/build-site-motion.cjs`, готовый браузерный файл `design/motion-bundle.js` (~74 КБ без сжатия).

Проверки: `node scripts/build-site-motion.cjs`, `node scripts/check-motion.cjs`, `node design/check-preview.cjs`, `node design/check-motion.cjs`. Последняя проверяет реальное промежуточное состояние анимации, быстрый выбор, переключение reduced motion во время работы и отсутствие ошибок JS. Проверены ширины 1440, 768, 390, 320 px. Производительность на физическом слабом телефоне не измерена.

Это работающая motion-концепция в макете, не публикация итогового сайта. Дальше — внутренние страницы, подтверждённые достижения, подключение заявок и SEO.
